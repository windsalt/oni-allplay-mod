# 缺氧mod

## 主要是用来一起玩游戏

主要应该包含以下一些功能

## 按功能分类

### 复制人

- [ ] 获取所有复制人信息(仅包含名字,id,当前位置)
- [ ] 复制人改名
- [ ] 判断小人是否被困住(通过移至判定即可)
- [ ] 切换排班

### 挖掘

- [ ] 挖掘指定位置的自然砖块(包含背景方块);

### 建造

- [ ] 在指定位置建造砖块,包含所有建筑类.

### 游戏本体

- [ ] 游戏倍数设置,获取
- [ ] 游戏自动保存间隔获取,设置
- [ ] 关闭自动杀毒
- [ ] 排班自动设置

### 房间信息

- [ ] 所有房间的信息

### 地图数据

- [ ] 获取已探明的地图数据,可指定区域大小

```Mermaid
sequenceDiagram
    玩家->>打印舱: 打开打印界面
    打印舱->>系统: 随机生成选项
    系统-->>打印舱: 返回4个选项
    打印舱-->>玩家: 显示选择
    玩家->>打印舱: 确认打印
    打印舱->>复制人: 生成小人
```
